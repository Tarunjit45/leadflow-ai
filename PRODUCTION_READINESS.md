# LeadFlow AI — Production Readiness Scorecard

| Category | Status | Evidence | Risk | Required Fix | Priority |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Authentication** | **GREEN** | Signed JWTs with `sub`, `business_id`, `role`, `session_version`; invalidates on password reset/logout; bcrypt hashing. | Session hijack if token is not revoked on logout. | Implemented session versioning checks in `deps.py`. | HIGH |
| **Authorization & RBAC** | **GREEN** | `get_current_business` extracts business membership strictly from authenticated `User.id` and JWT; refuses spoofed tenant IDs. | Cross-tenant data tampering. | Verified across all API v1 endpoints. | CRITICAL |
| **Account Lifecycle** | **GREEN** | `DELETE /api/v1/auth/account` cascades deletion to workspace, knowledge, agents, conversations, leads, and tokens. | Orphaned business records. | Verified cascading foreign keys. | HIGH |
| **Email Verification** | **GREEN** | Cryptographically secure tokens (`secrets.token_urlsafe(32)`), 24-hour expiration, single-use invalidation. | Unauthorized workspace activation. | Verified single-use token invalidation. | MEDIUM |
| **Password Reset** | **GREEN** | Single-use cryptographically random tokens, 1-hour expiration, increments `session_version` to invalidate all active JWTs. | Stale session access after account recovery. | Verified session version increment. | HIGH |
| **Onboarding Persistence** | **GREEN** | PostgreSQL database is source of truth; debounced draft autosave (`PATCH /step/{step}`); server validation; URL clamp to `allowed_step`. | Lost inputs, skip-ahead bypass. | 8/8 automated test suites passing. | CRITICAL |
| **Database Integrity** | **YELLOW** | Foreign key constraints with `CASCADE` on `businesses.id`, `users.id`, `conversations.id`. Overlapping appointment checking needed in `_handle_book_appointment`. | Double-booking race condition under concurrent traffic. | Implement transactional locking and time-overlap detection in appointment creation. | CRITICAL |
| **Multi-Tenancy** | **YELLOW** | All API routes filter by `business_id`. WhatsApp webhook fallback logic previously used `Business.order_by().first()` on unmapped numbers. | Inbound customer messages from unknown numbers routed to arbitrary business. | Remove unmapped fallback in `webhooks.py`; drop unmapped messages cleanly. | CRITICAL |
| **WhatsApp / Meta Integration** | **GREEN** | Embedded Signup config, Graph API v21.0 integration, SHA256 webhook HMAC verification, health check probe. | Invalid webhook payloads or unauthorized senders. | Strict HMAC verification + distinct owner vs customer handling. | HIGH |
| **AI Tool Permissions** | **YELLOW** | Tool registry enforces `allowed_tools_map`. Owner-only tools (`toggle_ai_automation`, KB updates) must be strictly stripped from customer conversations. | Prompt-injected customer could invoke administrative tools. | Strip owner-only tools from LLM tool schema when `sender_type != 'owner'`. | CRITICAL |
| **OpenRouter / AI Reliability** | **GREEN** | Fallback responses configured, timeout handling, secret filtering in model outputs via `safety.py`. | API outage or token leakage. | Sanitize outputs and maintain safe fallback messaging. | HIGH |
| **Prompt Security** | **GREEN** | Adversarial pattern matching regex (`sanitize_and_check_input`), redaction of API keys & tokens in `filter_output_for_secrets`. | Prompt injection leaking system prompts. | Keep AI isolated from backend security boundaries. | HIGH |
| **Calendar & Appointments** | **YELLOW** | Google Calendar provider, availability calculation. Slot overlap checking needed to guarantee atomicity. | Simultaneous bookings for the same time slot. | Add overlap query with `with_for_update()` in appointment reservation. | CRITICAL |
| **Follow-up Automation** | **GREEN** | Scheduled follow-up tasks cancel automatically when customer books, replies, or human agent takes over. | Duplicate or unwanted messages after conversion. | Validated in conversation status transitions. | MEDIUM |
| **Dashboard** | **GREEN** | Real-time queries for leads, conversations, revenue estimates, and appointments. | Stale UI metrics. | Strict tenant filtering on all analytics endpoints. | MEDIUM |
| **Dodo Payments & Billing** | **GREEN** | HMAC signature verification, `payment_provider_events` idempotency table, plan limits and subscription states. | Webhook replay attacks. | Database-level unique constraint on `(provider, provider_event_id)`. | HIGH |
| **Webhooks Idempotency** | **YELLOW** | Dodo uses DB table `payment_provider_events`. WhatsApp used in-memory dictionary `_processed_events`. | Replay of WhatsApp webhooks across server restarts or multi-worker setups. | Unify webhook idempotency to database table. | HIGH |
| **API & Backend Security** | **GREEN** | Sliding-window IP rate limiting on auth endpoints, CORS configured, parameterized SQLAlchemy queries prevent SQLi. | Brute force login or credential stuffing. | Rate limiter active on login, signup, password reset. | HIGH |
| **Frontend Security** | **GREEN** | Next.js 15 App Router, zero exposed backend secret keys in client bundle (`NEXT_PUBLIC_` limited to API URL). | Leaked private credentials. | Verified environment variables separation. | HIGH |
| **Rate Limiting** | **GREEN** | `rate_limiter.py` sliding window on `/auth/login`, `/auth/register`, `/auth/forgot-password`, `/auth/reset-password`. | DoS / credential guessing. | Active on all sensitive authentication routes. | HIGH |
| **Logging & Observability** | **GREEN** | Python standard logging with timestamps, service names, and sanitized payloads (no passwords/tokens logged). | Security leaks in log aggregators. | Redact passwords, tokens, and payment secrets in logs. | MEDIUM |
| **Error Handling** | **YELLOW** | Handled exceptions return clean JSON. Unhandled 500 exceptions need global sanitization to prevent stack traces leaking. | Raw stack trace or SQL syntax exposed to users. | Add FastAPI global exception handler for unhandled exceptions. | HIGH |
| **Mobile UX & Accessibility** | **GREEN** | Responsive Tailwind CSS layouts, touch-friendly tap targets, accessible dark theme design system. | Broken mobile experience. | Verified across desktop and mobile breakpoints. | MEDIUM |
